02. Tooling

The best hacking tool is already installed: your browser. Everything else is a bonus.

Browser DevTools

Open with F12, Ctrl+Shift+I (Windows/Linux) or Cmd+Option+I (Mac).

TabUse it to
ElementsInspect and edit the live HTML. Find hidden fields and comments.
ConsoleRun JavaScript on the page. Read document.cookie.
SourcesRead every JavaScript file the site loads. Developers leave secrets here.
NetworkWatch every request and response. Find hidden API endpoints.
ApplicationView and edit cookies and localStorage.

Quick wins

// View page source (raw HTML, including comments)
Ctrl+U  /  Cmd+Option+U

// In the Console
document.cookie                     // read cookies
document.cookie = "role=admin"      // set a cookie
atob("aGVsbG8=")                    // decode base64
btoa("hello")                       // encode base64

Burp Suite

Burp is an intercepting proxy. It sits between your browser and the server, letting you pause, read and change every request before it's sent.

Browser  ───►  Burp Suite  ───►  Server
               (you edit
                requests here)

Setup (Community Edition, free)

  1. Download from portswigger.net
  2. Start a temporary project with defaults
  3. Go to Proxy → Intercept → Open browser. Burp's built-in Chromium is already configured.
  4. Browse to a site and watch requests appear in Proxy → HTTP history

The features you'll use most

FeatureWhat it does
Proxy / InterceptPause a request, edit it, forward it
HTTP historyLog of everything your browser sent
RepeaterResend one request over and over with tweaks. Your main workbench.
DecoderEncode and decode base64, URL, HTML...
For today Every lab in this workshop runs inside your browser, so DevTools alone is enough to solve all of them. Burp is the tool you'll want for real targets, so set it up afterwards.
